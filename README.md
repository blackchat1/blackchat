# 私密消息 · README

一个基于**公开安全的网络服务**的端到端加密聊天客户端，提供 **Windows 桌面版（exe）** 与 **Android 版**，两端协议一致、房间互通。

---

## 架构概览

```
┌─────────────┐        ┌──────────────────────┐        ┌─────────────┐
│  桌面版 exe │ ◄────► │  公开安全的网络服务  │ ◄────► │  Android 版 │
└─────────────┘        └──────────────────────┘        └─────────────┘
       │                        ▲                              │
       │                        │ 只保存密文                    │
       └────────────────────────┴──────────────────────────────┘
              客户端 AES-256-GCM 加密 / Ed25519 签名
```

**工作方式：**

1. **客户端加密**：消息、图片、附件、房间索引在上传前，由客户端用 AES-256-GCM 加密；解密密钥只存在分享链接的 `#` 片段中，**从不发给服务端**。
2. **服务端只存密文**：公开安全的网络服务只承担"保存一段不可读的密文、按时间或令牌删除"这一件事，**不保存任何明文消息、文件名、昵称或身份信息**。
3. **消息签名**：每条消息在加密层内部附加 Ed25519 数字签名，服务端无法篡改正文或冒充已知设备。
4. **房间与分片**：一个房间由一个加密索引 + 若干加密分片组成；分片写满自动扩容，无需手动维护。
5. **可靠投递**：发送前先把签名信封落盘，网络中断/崩溃后重连自动补发，服务端按稳定 `message_id` 去重。

## 优势

| 优势 | 说明 |
| --- | --- |
| **端到端加密** | 服务端永远看不到明文；密钥只在分享链接里，服务器无从获取 |
| **服务端零知识** | 除密文外不保存任何可读信息：无账号、无联系人、无访问历史 |
| **无需自建服务器** | 直接复用公开安全的网络服务，无需运维、无需备案 |
| **消息不丢** | 持久待发队列 + 稳定消息 ID，断网重连自动补发，服务端去重 |
| **身份可验证** | 设备独立 Ed25519 密钥，房主公钥固定在加密索引内，可带外核对指纹 |
| **跨平台互通** | 桌面版与 Android 版共享同一套协议核心，房间完全互通 |
| **可选 Tor** | 桌面版内置 SOCKS5，Android 可配合 Orbot，隐藏网络层来源 |
| **桌面版更稳** | 无后台限制、文件选择器原生、文件保存可见，适合主力长期使用 |

## 平台选择建议

| 场景 | 推荐 |
| --- | --- |
| 长期挂房间、频繁传文件、主力使用 | **Windows 桌面版（exe）** |
| 移动场景、临时沟通 | Android 版（功能完整，建议用完主动断开） |

两端可同时进入同一房间，各自身份独立、消息互相同步。
